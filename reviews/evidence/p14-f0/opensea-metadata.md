# OpenSea metadata 官方规范核验

核验日期：2026-09-06。OpenSea 官方当前要求 ERC-721 由 tokenURI 返回 JSON；支持 ar://；collection 级 metadata 用 ERC-7572 contractURI，creator attribution 使用 ERC-173。Pond Echoes 的 name/description/image/animation_url/external_url/attributes、永久 Arweave URI、contractURI 与 Ownable 方向一致。

- https://docs.opensea.io/docs/metadata-storage
- https://docs.opensea.io/docs/contract-level-metadata
